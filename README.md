# Electrónica Alex

## Resumen

Electrónica Alex es un programa realizado en Python para llevar un mejor control de los televisores que ingresan a un taller de reparación.
El programa permite registrar los datos de los clientes y sus televisores, buscar información, actualizar el estado de las reparaciones y registrar las compras de repuestos.
También permite consultar los televisores registrados y obtener un reporte con los gastos, presupuestos, cobros y balance del taller. Los datos se guardan en archivos para poder utilizarlos cuando se vuelva a ejecutar el programa.

## Funciones del programa

1. Registrar ingreso de televisores.
2. Buscar registros por DNI, nombre o celular.
3. Actualizar estado de reparación.
4. Registrar compra de repuestos.
5. Listar y filtrar ingresos.
6. Generar reportes de compras y ventas.
7. Guardar y cargar información.
